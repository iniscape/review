# Changelog

## 0.1.3

Changes:

- Add a You commented list of reviews.
- Add support for comparing two commits or a range.
- Add support for outdated and file-level threads.
- Add support for name:line in a review's Quick Launch.
- Add links for commit SHAs in comments and messages.
- Add avatars to History, Blame and your own drafts.
- Add Gravatar fallback for commit authors.
- Add Clear Cache in Settings.
- Add tooltips on status marks and reviewer avatars.
- Show inline code in comments on a shaded chip.
- Show resolved threads while Resolved is on.
- Update the status marks and the macOS app icon.
- Sync every 10 minutes by default.
- Fix arrow keys and Tab on the Reviews tab.
- Fix avatars showing initials after a restart.
- Fix sync missing threads resolved on the service.
- Fix a button's hover staying after the pointer left.
